Q12 Accessibility Compliance & Implementation Report

Candidate: Rahul Mehra | Department: CSE AIML (Section B)

Assignment Target: Inventory Management System — Question 12 (Improve Accessibility)

1. High Contrast Mode (WCAG AAA Compliance)

Designed for users with low vision, photophobia, or visual impairments. Implements ultra-high contrast color ratios exceeding 7:1 for normal text and 4.5:1 for UI components.

  • Uses pure OLED black backgrounds (#000000) paired with stark high-contrast yellow (#FFE600), cyan (#00FFFF), and pure white (#FFFFFF).
  • Replaces subtle box shadows and gray borders with bold 2px/3px solid borders to guarantee unambiguous visual demarcation of buttons, inputs, and rows.
  • Interactive elements receive clear underline and outline indicators that do not rely solely on color cues.

2. Dynamic Font Resizing Engine

Enables real-time scaling without page zooming or breaking responsive flexbox/grid containers.

  • Provides step-based controls (A-, A+, and Reset) with visual feedback (85% to 175%).
  • Built entirely on CSS custom properties (--font-scale) combined with scalable rem units.
  • Ensures no text truncation, overlapping, or horizontal overflow when scaled up to 175%.
  • Persistent across page reloads via localStorage.

3. Comprehensive Keyboard Navigation (WCAG 2.1 Principle 2)

Ensures the entire inventory workflow is completely operable without a mouse.

  • Skip to Main Content: Top visible link allows immediate bypass of header and toolbar.
  • Visible Focus Indicators: High-visibility 3px glowing outline with 2px offset on all interactive elements.
  • Modal Focus Trapping: Focus is strictly kept within active modal dialogs, and returned to trigger button upon dismissal.
  • Keyboard Hotkeys: Alt+N (New Item), Alt+S (Search), Alt+H (High Contrast), Alt+D (Dark Theme), Alt+M (Minimalist Mode), Esc (Close/Exit).
  • Table Row Traversal: Arrow keys enable rapid keyboard scanning through rows.

4. Dark Mode with System Intelligence

Reduces eye strain and power consumption for extended laboratory sessions.

  • Engineered with accessible slate dark tones (#0f172a, #1e293b) tested for zero glare and high contrast.
  • Can be toggled independently or combined with High Contrast Dark for ultra-stark contrast.

5. Minimalist Cognitive Layout Mode

Caters to neurodivergent users, individuals with ADHD, cognitive overload sensitivity, or users on screen magnifiers.

  • Removes decorative metric cards, secondary badges, visual gradients, and motion transitions.
  • Distills the interface into clean, high-legibility tabular data with generous padding and focused typography.
  • Drastically simplifies cognitive load during stock entry and verification.

6. Screen Reader & ARIA Support

Implements aria-live="polite" for real-time stock updates and search result tallies, proper aria-describedby error handling on inputs, and explicit role="alertdialog" for destructive delete operations.
